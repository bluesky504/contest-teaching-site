# 比赛页简介的系统核对

2026-10-08 实际打开当前比赛页「提示 → 简介」，按全文而非只按法术表核对。当前联盟标题为「AI世青赛全国(2027)联盟」，地图为 `mages-might`。原始表头、表格与段落快照：`docs/reports/003/battle-intro-20261008.json`。这是界面文档证据，不等同于逐帧实测；报告目录可能不随 Git 分发。

## 果农与采集

- 初始有一名果农，用 `hero.spawnCollector()` 生成更多果农。
- 简介列出的第2至第9名生成时间依次为1、3、9、18、27、36、45、54；这是文档原值，不擅自改写成实测调用耗时，也不把策略当前限制六果农当成地图最大数量。
- 果农采到水果后返回生成点，随后调用 `hero.chooseItem` 请求下一目标。策略应先设置回调，再生成和调度果农。
- 简介声称 `hero.collectors`、`hero.opponent.collectors` 可用，但已有 JS 逐字段实测证明这些属性读取会被拦截，不能按旧说明重新使用。有效入口是 `hero.findMyCollectors()` 和 `hero.findEnemyCollectors()`；字段是否可读以 `api.json` 为准。

## 法术表的列义

原表头依次是「名字 / 魔法mana / 费用 / 法力 / 持续时间(s)」。

| 列 | 正确使用 |
|---|---|
| 魔法mana | 元素种类，如 fire/water/earth；不是法力点数 |
| 费用 | 本方消耗的元素法力，对应 `getSpellData().cost` |
| 法力 | 攻击威力或特殊法术效果量，对应 `getSpellData().power`，不是消耗 |
| 持续时间 | 仅保留为界面文档说明；不能自动解释为飞行时间、冷却时间或护盾寿命 |

箭：费用3、威力25；光束：费用7、威力75；球：费用15、威力200。三种攻击的「法力」栏是无保护条件下的攻击威力基准；遇到盾后的真实扣血仍由命中帧核对。

简介写球的持续时间4、盾0、burn/refresh 1.5、grow 5；现有 API 实测 `duration` 分别是3、1、5、2。保留差异，不能直接用简介覆盖已实测字段，也不能据盾0宣称已证明无限寿命。

## 相克的方向

简介明确：**火克土、水克火、土克水**。

| 我方护盾 | 克制并防御的攻击元素 | 克制该护盾的攻击元素 |
|---|---|---|
| 火盾 | 土 | 水 |
| 水盾 | 火 | 土 |
| 土盾 | 水 | 火 |

例如土盾面对火球不是「土克火」：火克土，火球可能穿透并打碎土盾。规则方向来自简介；护盾是否挡住、扣多少耐久、同元素如何处理和箭/光束/球是否一致，需要相应配对的实测支持，不能把某一格外推成27格全部已测。

## 施法与特殊魔法

- `hero.canCast()` 核对可施放条件，`hero.cast()` 执行施法；费用足够不等于一定能施放。`duration` 与运行时动作窗口分别记录，不混为一谈。
- `fire-burn` 减少敌方果农血量；简介费用10、效果量5。
- `water-refresh` 增加己方果农血量；简介费用10、效果量10，不是英雄治疗。
- `earth-grow` 增大己方水果；简介费用10、效果量1.5。实际生长速率、作用窗口、采集收入与扣费后的净效果应分开核对。
