# 五课与本地工具审阅清单

这份清单用于教师首次通读五课和手动快照查看工具，不是新的技术验收或独立复验。建议按顺序浏览首页、五个课页和 `tools/timeline-viewer.html`；每项只需标记「通过 / 修改 / 暂不判断」，不要因为页面能打开就把教学结论当成比赛事实。

## 总体边界

- [ ] 页面明确写着教学草稿、未实战或未发布的位置没有被隐藏。
- [ ] 2027 页面说明、2026 历史 API/事实和教学假设没有混成一层。
- [ ] `unknown`、样本不足、历史继承和未独立复验的状态仍然可见。
- [ ] 课程没有承诺胜率、最优策略或真人对手效果。
- [ ] 下载的第二至第四课示例没有被页面自动执行；第五课是静态记录对象。
- [ ] 参赛版源码没有被教学页直接公开或复制进课程示例。

## 逐课问题

### 第一课：规则与可用接口

- [ ] 学生能解释 mana 类型、费用、威力和持续时间不是同一个量。
- [ ] 学生能区分文档说明、观测证据和策略假设。
- [ ] `getTotalMana("元素")` 的单池参数和 `findEnemyMissiles()` 的字段边界讲清楚。
- [ ] 小练习不会诱导学生把护盾消失直接写成自然到期。

### 第二课：采集与基本攻击

- [ ] 学生能解释 `chooseItem`、单池法力、费用门槛和 `canCast` 的先后关系。
- [ ] 学生知道 `cast` 调用或返回值不等于命中、掉血或获胜。
- [ ] 无限主循环的“不可直接用 Node/网页执行”警示足够醒目。
- [ ] 三种假设输入被理解为独立分支，不被误读为连续对局。

### 第三课：扩张与阻塞取舍

- [ ] 简介原值、历史实测间隔和页面假设模型分开阅读。
- [ ] 学生不会把英雄调用阻塞推导成所有果农停止采集。
- [ ] `max(0, 剩余时间－阻塞)` 被理解为教学模型，不是收入或回本证明。
- [ ] 未知威胁显示无法评估，而不是自动判定安全。

### 第四课：攻防预算

- [ ] 学生理解已知火来袭、防御预算、无来袭攻击和未知等待是四种不同分支。
- [ ] `shieldUsed` 被理解为示例预算，而不是平台证明的护盾次数上限。
- [ ] 空的飞弹列表没有被解释成对手永远不会攻击。
- [ ] 相克规则与护盾寿命、冷却和未验证飞弹字段保持边界。

### 第五课：复盘与知识归纳

- [ ] 学生能写出问题、假设、唯一主要改动、控制项和下一测。
- [ ] 四类标签能区分：文档说明、运行观测、策略假设、未知。
- [ ] 结论没有超过证据；失败和 unknown 没有被删除。
- [ ] 下一测能明确只改变一个主要因素，并写出成功/失败判据。

### 本地手动快照查看工具

- [ ] 学生能区分手动快照查看与比赛回放、结果判定和正式证据验收。
- [ ] 文件只在当前标签页内存中读取；页面没有上传、自动保存、源码执行或比赛控制路径。
- [ ] 缺帧、缺字段、读取失败和前20帧预热状态仍显示为边界或 `unknown`，没有被补成0、死亡或胜负。
- [ ] `mana` 的元素字符串、来源未核实和虚构教学示例的标签足够醒目，不会被误读成法力数量或实测结果。
- [ ] 文件大小限制、恶意文本展示和导入失败保留上一份等安全行为不影响正常教学使用。
