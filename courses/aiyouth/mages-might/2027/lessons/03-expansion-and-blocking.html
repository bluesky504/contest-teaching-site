01

ONE CHANGE ONLY

只增加一次生成调用

和第二课相比，唯一的新行为是主循环前的 hero.spawnCollector()。它返回后，才进入相同的攻击循环。

一次扩张尝试 JavaScript
var gatheringElement = "fire";
var attackSpell = "fire-arrow";
var attackCost = 3;

hero.chooseItem = function (collector) {
  return gatheringElement;
};

hero.spawnCollector();

while (true) {
  var availableMana = hero.getTotalMana(gatheringElement);
  if (availableMana >= attackCost && hero.canCast(attackSpell)) {
    hero.cast(attackSpell);
  }
}
只验证调用顺序；不依赖生成返回值，也不声明出生成功。

02

A SMALL HYPOTHESIS MODEL

调整假设，观察取舍

只计算“返回后剩余多少窗口”和“按假设速率能增加多少法力”。它忽略首趟往返、排队、死亡、攻击消耗和真实入账，不是比赛模拟。

新增采集窗口16 秒
额外法力假设量8 法力

示意威胁不晚于生成返回：不能等生成完再处理。正收入不等于值得扩张。

记住

正收入只说明模型里有产出，不说明已经回本；威胁未知时，更不能把未知当成安全。
